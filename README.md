# Supply Chain Analytics Dashboard

## Project Overview
A Python-based interactive dashboard for analyzing supply chain operations, inventory levels, supplier performance, delivery reliability, and transportation costs.

## Features
- Interactive supply chain KPI dashboard
- Inventory monitoring and reorder recommendations
- Inventory risk classification
- Supplier performance analysis
- Logistics and shipping cost analysis
- Delivery delay monitoring
- Data quality checks
- CSV downloads for analysis results

## Technologies Used
- Python
- Pandas and NumPy
- Streamlit
- Plotly
- CSV and Excel data processing

## Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the dependencies:

   `python -m pip install -r requirements.txt`

4. Generate sample data if the CSV files are missing:

   `python generate_data.py`

5. Launch the dashboard:

   `python -m streamlit run app.py`

## Project Purpose
This project demonstrates practical skills in data analysis, data visualization, inventory management, and supply chain decision support.

The project uses sample data for demonstration and educational purposes.
